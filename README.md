# AI Data Workflows

A personal project exploring practical workflows for data processing, Python automation, and cloud integrations that support AI and data engineering tasks.

## Project pages

- Homepage: `index.html`
- Privacy policy: `privacy.html`

## Scope

This project is intended for the maintainer's personal use. When configured, its workflows can access the maintainer's Google Drive to ingest, organize, transform, and report on files authorized by the maintainer.

The public site describes the project at a high level. The privacy policy explains the actual data access and handling.

## Publish with GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.
5. Confirm the homepage and `/privacy.html` are publicly accessible before entering their URLs in Google Cloud Console.

Never add OAuth client secrets, refresh tokens, private exports, or personal datasets to this public repository.
